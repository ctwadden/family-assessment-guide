# Family Assessment Guide

A 2-minute-21-second narrated guide for families in Communications Technology 11 and Multimedia 12 at Halifax West.

The guide explains products, conversations, observations, the course assessment-title convention, formative feedback, summative evidence, and next steps. A felt-character introduction is followed by simple animated diagrams. Includes English captions, chapter controls, reduced-motion playback and the complete written explanation.

All illustrated classroom examples are fictional. Narration uses the synthetic Sarah voice. The school’s supplied P/C/O communication informs the explanation; the FORM/SUM title format is a local course convention. No official software or departmental endorsement is implied.
